## 🏗 组件层次结构

### 第 1 层：页面入口
```
web/app/(shareLayout)/chat/[token]/page.tsx
└── 导出 Chat 组件（使用 React.memo 优化）
```

**组件代码**：
```tsx
const Chat = () => {
  return (
    <AuthenticatedLayout>
      <ChatWithHistoryWrap />
    </AuthenticatedLayout>
  )
}
```

**职责**：
- 定义路由页面
- 提供认证布局包装
- 加载主聊天组件

---

### 第 2 层：认证布局
```
web/app/(shareLayout)/components/authenticated-layout.tsx
└── 处理用户认证和权限检查
```

**职责**：
- 验证用户访问权限
- 检查应用 token 有效性
- 提供布局容器

---

### 第 3 层：聊天历史包装器
```
web/app/components/base/chat/chat-with-history/index.tsx
├── ChatWithHistoryWrapWithCheckToken（外层）
│   └── 检查 token 和应用可用性
├── ChatWithHistoryWrap（中间层）
│   └── 提供 Context 和状态管理
└── ChatWithHistory（内层）
    └── 渲染实际UI
```

**三层结构说明**：

#### ChatWithHistoryWrapWithCheckToken
- 最外层包装
- 检查 access token
- 处理应用不可用状态
- 显示 loading 或错误页面

#### ChatWithHistoryWrap
- 使用 `useChatWithHistory` hook 管理状态
- 提供 `ChatWithHistoryContext` 给子组件
- 管理对话列表、当前对话、输入表单等状态

#### ChatWithHistory
- 实际渲染 UI 的组件
- 消费 Context 中的数据
- 组织页面布局结构

---

### 第 4 层：主要 UI 组件

#### A. 侧边栏（Sidebar）
**文件**：`web/app/components/base/chat/chat-with-history/sidebar/index.tsx`

**布局位置**：页面左侧，宽度 236px

**主要功能**：
- 显示应用图标和标题
- 侧边栏折叠/展开按钮
- "New Chat" 按钮
- 对话历史列表
  - 置顶对话（Pinned）
  - 普通对话（Unpinned）
- "Powered by Dify" 底部标识

**关键样式类**：
```tsx
className="flex w-[236px] flex-col p-1 pr-0 transition-all duration-200 ease-in-out"
```

**子组件**：
- `List` - 对话列表
- `RenameModal` - 重命名对话模态框
- `Confirm` - 删除确认对话框

---

#### B. 头部（Header）
**文件**：`web/app/components/base/chat/chat-with-history/header/index.tsx`

**布局位置**：主内容区顶部，高度 56px（14 * 4px）

**显示条件**：仅在桌面端显示（移动端使用 HeaderInMobile）

**主要功能**：
- 侧边栏展开/折叠按钮（当侧边栏折叠时显示）
- 应用图标和名称
- 当前对话名称和操作（置顶、重命名、删除）
- "New Chat" / "Reset Chat" 按钮
- 查看表单下拉菜单（View Form Dropdown）

**关键样式类**：
```tsx
className="flex h-14 shrink-0 items-center justify-between p-3"
```

---

#### C. 聊天包装器（ChatWrapper）
**文件**：`web/app/components/base/chat/chat-with-history/chat-wrapper.tsx`

**布局位置**：主内容区中间，占据剩余空间

**主要功能**：
- 管理聊天消息状态
- 处理消息发送逻辑
- 渲染实际的聊天组件（Chat）
- 处理建议问题（Suggested Questions）
- 管理对话输入表单

**依赖的核心组件**：
- `Chat` - 基础聊天组件（来自 `../chat`）
- `InputsForm` - 对话输入表单
- `useChat` hook - 聊天逻辑管理

## 🔄 状态管理

### Context 提供的状态
```typescript
ChatWithHistoryContext {
  // 应用数据
  appData                    // 应用配置和信息
  appParams                  // 应用参数
  appMeta                    // 应用元数据

  // 对话相关
  currentConversationId      // 当前对话 ID
  currentConversationItem    // 当前对话详情
  pinnedConversationList     // 置顶对话列表
  conversationList           // 普通对话列表

  // 输入相关
  newConversationInputs      // 新对话输入值
  currentConversationInputs  // 当前对话输入值
  inputsForms                // 输入表单配置

  // 操作方法
  handleNewConversation      // 创建新对话
  handleStartChat            // 开始聊天
  handleChangeConversation   // 切换对话
  handlePinConversation      // 置顶对话
  handleUnpinConversation    // 取消置顶
  handleDeleteConversation   // 删除对话
  handleRenameConversation   // 重命名对话

  // UI 状态
  sidebarCollapseState       // 侧边栏折叠状态
  isMobile                   // 是否移动端
  isResponding               // 是否正在响应

  // 其他
  themeBuilder               // 主题构建器
  handleFeedback             // 反馈处理
}
```

### Hook：useChatWithHistory
**文件**：`web/app/components/base/chat/chat-with-history/hooks.tsx`

**功能**：
- 管理对话列表状态
- 处理对话操作逻辑
- 管理输入表单状态
- 处理 API 请求

### 移动端特殊处理
- 使用 `HeaderInMobile` 替代 `Header`
- 侧边栏完全隐藏（不是折叠）
- 布局从横向改为纵向 `flex-col`
