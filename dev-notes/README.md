## 🚀 快速开始

### ⚠️ 首次部署必读

如果你是**首次从 Git 克隆项目**，在启动 Docker 前必须先构建自定义镜像：

```bash
# 在项目根目录执行（首次部署必需！）
docker build -t langgenius/dify-web:brand-customization ./web
```

**为什么？** 自定义镜像 `langgenius/dify-web:brand-customization` 只存在于本地，不在 Docker Hub 上。

详见：[部署问题排查/2025-11-03-品牌化镜像不存在错误.md](./部署问题排查/2025-11-03-品牌化镜像不存在错误.md)
