## 🚀 快速开始

### 开发服务器启动
```bash
# 终端 1：保持 Docker 后端运行
cd /Users/stephen/Downloads/00_project/08_Dify_测试整体效果/01_测试前端分离/docker
docker compose up -d

# 终端 2：启动前端开发服务器
cd /Users/stephen/Downloads/00_project/08_Dify_测试整体效果/01_测试前端分离/web
pnpm dev
```

### 访问地址
- 前端开发服务器：http://localhost:3000
- Docker 完整应用：http://localhost:80
- 后端 API：http://localhost:5001
- 目标聊天页面：http://localhost:3000/chat/l8BpY79pZD0AVs9E
