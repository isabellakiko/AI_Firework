### 2. 修复按钮 CSS Bug（关键修复）

**文件**：`web/app/components/base/button/index.css`

**位置**：第 94-110 行

**问题**：`btn-secondary-accent` 使用了错误的 CSS 变量，导致黄色主题不生效

**修改内容**：
```css
/* 修改前（错误） */
.btn-secondary-accent {
  @apply
  bg-components-button-secondary-bg              /* ❌ 错误变量 */
  border-components-button-secondary-border      /* ❌ 错误变量 */
  hover:bg-components-button-secondary-bg-hover  /* ❌ 错误变量 */
  /* ... */
}

/* 修改后（正确） */
.btn-secondary-accent {
  @apply
  bg-components-button-secondary-accent-bg              /* ✅ 正确变量 */
  border-components-button-secondary-accent-border      /* ✅ 正确变量 */
  hover:bg-components-button-secondary-accent-bg-hover  /* ✅ 正确变量 */
  /* ... */
}
```

**说明**：这是原代码的 bug，修复后才能让黄色按钮生效

### 6. 对话列表项文字

### 10. 优化选中对话项背景（最终修复）

**文件**：`web/app/components/base/chat/chat-with-history/sidebar/item.tsx`

**位置**：第 33-39 行

**问题**：选中对话的蓝色背景 `bg-state-accent-active` 在深灰背景上对比度不足

**修改内容**：
```tsx
/* 修改前 */
<div
  className={cn(
    'system-sm-medium group flex cursor-pointer rounded-lg p-1 pl-3 hover:bg-state-base-hover',
    isSelected && 'bg-state-accent-active hover:bg-state-accent-active',
  )}
  style={{
    color: isSelected ? '#f2c823' : '#e0e0e0'
  }}
>

/* 修改后 */
<div
  className={cn(
    'system-sm-medium group flex cursor-pointer rounded-lg p-1 pl-3 hover:bg-state-base-hover',
  )}
  style={{
    color: isSelected ? '#f2c823' : '#e0e0e0',
    backgroundColor: isSelected ? 'rgba(242, 200, 35, 0.15)' : 'transparent'
  }}
>
```

**效果**：
- 选中对话：黄色文字 + 半透明黄色背景（15% 透明度）
- 普通对话：浅灰文字 + 透明背景
- 在深灰色侧边栏上对比清晰，品牌色突出

## 已解决的问题

1. ✅ **按钮 CSS Bug**：原代码中 `btn-secondary-accent` 类使用了错误的变量
   - 问题：黄色按钮主题不生效
   - 解决：修复 CSS 类使用正确的变量名

2. ✅ **三种侧边栏背景不一致**：
   - 问题：正常侧边栏、Hover 面板、移动端侧边栏背景色不统一
   - 解决：统一为深灰色 #615e5f

3. ✅ **选中对话背景对比度不足**：
   - 问题：蓝色背景在深灰色上看不清
   - 解决：改为半透明黄色背景 `rgba(242, 200, 35, 0.15)`

4. ✅ **文字颜色在深灰背景上不可读**：
   - 问题：深色文字在深灰背景上对比度差
   - 解决：标题改为浅色 #f9fafb，对话项改为浅灰 #e0e0e0
