# 发送框品牌化定制

## 修改信息

- **日期**：2025-10-28
- **修改类型**：样式 + 品牌化设计
- **影响范围**：聊天发送框（输入框、发送按钮）
- **测试状态**：✅ 已完成并通过测试

---

## 设计方案

**目标**：将发送框（消息输入区域）融入品牌色系统，与侧边栏的品牌配色保持一致。

**品牌色**：
- 黄色：#f2c823（主强调色 - 按钮、文字、交互）
- 深灰：#615e5f（专业色 - 图标、容器）

**设计思路**：
- 发送按钮使用黄色背景，与 "New Chat" 按钮统一
- 输入框文字和 Placeholder 使用黄色，突出品牌感
- Focus 状态添加黄色边框和发光效果，增强交互反馈
- 箭头图标使用深灰色，与侧边栏呼应

---

## 修改详情

### 1. 发送按钮改为黄色主题

**文件**：`web/app/components/base/chat/chat/chat-input-area/operation.tsx`

**位置**：第 60 行

**修改内容**：
```tsx
/* 修改前 */
<Button
  className='ml-3 w-8 px-0'
  variant='primary'              // 蓝色主题
  onClick={onSend}
  style={
    theme
      ? { backgroundColor: theme.primaryColor }
      : {}
  }
>
  <RiSendPlane2Fill className='h-4 w-4' />
</Button>

/* 修改后 */
<Button
  className='ml-3 w-8 px-0'
  variant='secondary-accent'     // 黄色主题
  onClick={onSend}
>
  <RiSendPlane2Fill className='h-4 w-4' />
</Button>
```

**效果**：
- 发送按钮背景变为黄色 #f2c823
- Hover 时变为深黄色 #e0b61f
- 与 "New Chat" 按钮样式完全一致

---

### 2. 输入框文字和 Placeholder 黄色化

**文件**：`web/app/components/base/chat/chat/chat-input-area/index.tsx`

**位置**：第 195-198 行

**修改内容**：
```tsx
/* 修改前 */
<Textarea
  className={cn(
    'body-lg-regular w-full resize-none bg-transparent p-1 leading-6 text-text-primary outline-none',
  )}
  placeholder={t('common.chat.inputPlaceholder', { botName }) || ''}
/>

/* 修改后 */
<Textarea
  className={cn(
    'body-lg-regular w-full resize-none bg-transparent p-1 leading-6 outline-none placeholder:text-[#f2c823] placeholder:opacity-70',
  )}
  style={{ color: '#f2c823' }}
  placeholder={t('common.chat.inputPlaceholder', { botName }) || ''}
/>
```

**效果**：
- 移除 `text-text-primary`（原深色文字）
- 输入文字颜色：黄色 #f2c823
- Placeholder 颜色：黄色 #f2c823（70% 透明度，更柔和）

---

### 3. 输入框 Focus 微妙黄色效果

**文件**：`web/app/components/base/chat/chat/chat-input-area/index.tsx`

**位置**：第 174-175 行

**修改内容**：
```tsx
/* 修改前 */
<div
  className={cn(
    'relative z-10 rounded-xl border border-components-chat-input-border bg-components-panel-bg-blur pb-[9px] shadow-md',
    isDragActive && '...',
    disabled && '...',
  )}
>

/* 修改后 */
<div
  className={cn(
    'relative z-10 rounded-xl border border-components-chat-input-border bg-components-panel-bg-blur pb-[9px] shadow-md transition-all duration-200',
    'focus-within:border-[#f2c823] focus-within:shadow-[0_0_0_3px_rgba(242,200,35,0.1)]',
    isDragActive && '...',
    disabled && '...',
  )}
>
```

**效果**：
- 添加 `transition-all duration-200` - 平滑过渡动画
- `focus-within:border-[#f2c823]` - 聚焦时黄色边框
- `focus-within:shadow-[0_0_0_3px_rgba(242,200,35,0.1)]` - 聚焦时浅黄色外发光

---
