### 模块一：侧边栏品牌化

#### 1.1 侧边栏背景色

**位置**：页面左侧侧边栏

**验证方法**：
1. 打开页面
2. 观察侧边栏背景色

**预期效果**：
- [ ] 侧边栏背景是深灰色（#615e5f）
- [ ] 背景色覆盖整个侧边栏区域

## 🔍 常见问题排查

### 问题 1：颜色不对或没有变化

**可能原因**：
- 浏览器缓存
- 代码没有正确应用
- Docker 镜像没有更新

**解决方法**：
1. 强制刷新浏览器（Cmd+Shift+R）
2. 检查代码修改是否正确
3. 验证 Docker 镜像 SHA（参考部署文档）
4. 清除浏览器缓存后重试

---

### 问题 2：部分元素生效，部分不生效

**可能原因**：
- 部分文件修改遗漏
- 代码修改不完整

**解决方法**：
1. 对照 "01-前端代码修改清单.md" 逐个检查
2. 使用浏览器开发者工具检查元素
3. 查看控制台是否有错误

---

### 问题 3：用户头像颜色偏橙色

**可能原因**：
- User.json 的不透明度未调整（仍是 0.68）

**解决方法**：
1. 打开 `User.json` 文件
2. 确认 circle 和 ellipse 的 opacity 是 `0.99`（不是 0.68）
3. 重新构建镜像

---

### 问题 4：移动端侧边栏没有深灰背景

**可能原因**：
- `header-in-mobile.tsx` 未修改

**解决方法**：
1. 检查 `header-in-mobile.tsx` 约第 110 行
2. 确认添加了 `style={{ backgroundColor: '#615e5f' }}`
3. 重新部署

---

### 问题 5：Hover 面板没有深灰背景

**可能原因**：
- `sidebar/index.tsx` 的 Panel 模式未修改

**解决方法**：
1. 检查 `sidebar/index.tsx` 约第 82-88 行
2. 确认添加了 `style={{ backgroundColor: '#615e5f' }}`
3. 确认移除了 `bg-components-panel-bg` class
