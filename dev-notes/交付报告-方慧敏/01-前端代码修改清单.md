## 📝 重要提示

1. **行号仅供参考**，请根据代码内容和注释定位，不同版本的 Dify 行号可能不同

2. **User.json 不透明度调整很关键**，从 0.68 改为 0.99，否则黄色会与深灰混合变成深橙色

3. **按钮 CSS bug 必须修复**（1.8），否则黄色按钮不生效

4. **三处侧边栏背景都要修改**：
   - 主容器（index.tsx 第62行）
   - Panel 模式（sidebar/index.tsx 第82行）
   - 移动端（header-in-mobile.tsx 第110行）

5. **建议修改顺序**：按模块顺序修改，每完成一个模块就 Git 提交一次
