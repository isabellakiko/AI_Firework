# 侧边栏实现详解

## 📖 文档用途

本文档详细记录 Dify 聊天应用侧边栏的 3 种显示方式、控制逻辑和代码实现，方便后续修改时快速定位。

## 🎯 侧边栏的 3 种显示方式

### 概览

| 显示方式 | 平台 | 触发方式 | 宽度 | 定位方式 | isPanel |
|---------|------|---------|------|---------|---------|
| **正常侧边栏** | 桌面端 | 默认显示 | 236px | 相对定位 | ❌ 否 |
| **Hover 面板** | 桌面端 | 鼠标靠近左边缘 | 256px | 绝对定位 | ✅ 是 |
| **弹出侧边栏** | 移动端 | 点击菜单按钮 | 100vw-40px | 固定定位 | ❌ 否 |

## 🖥️ 桌面端 - 正常侧边栏

### 代码位置

**文件**：`web/app/components/base/chat/chat-with-history/index.tsx`
**行数**：第 58-64 行

### 完整代码

```tsx
{!isMobile && (
  <div className={cn(
    'flex w-[236px] flex-col p-1 pr-0 transition-all duration-200 ease-in-out',
    isSidebarCollapsed && 'w-0 overflow-hidden !p-0',
  )} style={{ backgroundColor: '#615e5f' }}>
    <Sidebar />
  </div>
)}
```

### 代码解析

**条件渲染**：
```tsx
{!isMobile && ...}
```
- 只在非移动端显示
- 移动端使用 `HeaderInMobile` 代替

**容器样式**：
```tsx
className={cn(
  'flex w-[236px] flex-col p-1 pr-0 transition-all duration-200 ease-in-out',
  isSidebarCollapsed && 'w-0 overflow-hidden !p-0',
)}
```
- `flex` - Flexbox 布局
- `w-[236px]` - 宽度 236px
- `flex-col` - 垂直方向排列
- `p-1 pr-0` - 内边距 4px，右边距 0
- `transition-all duration-200` - 平滑过渡动画（200ms）
- `ease-in-out` - 缓动函数

**折叠状态**：
```tsx
isSidebarCollapsed && 'w-0 overflow-hidden !p-0'
```
- 当 `isSidebarCollapsed === true` 时：
  - `w-0` - 宽度变为 0
  - `overflow-hidden` - 隐藏溢出内容
  - `!p-0` - 强制清除所有内边距

**品牌色背景**：
```tsx
style={{ backgroundColor: '#615e5f' }}
```
- 深灰色品牌背景

**Sidebar 组件**：
```tsx
<Sidebar />
```
- 无 `isPanel` prop，使用正常模式

### 状态控制

**控制变量**：`sidebarCollapseState`（来自 Context）

**控制逻辑**：
```tsx
const { sidebarCollapseState } = useChatWithHistoryContext()
const isSidebarCollapsed = sidebarCollapseState
```

**切换方法**：`handleSidebarCollapse(boolean)`

**触发位置**：Sidebar 内的折叠/展开按钮
- 展开按钮：`sidebar/index.tsx:102`（`RiExpandRightLine`）
- 折叠按钮：`sidebar/index.tsx:107`（`RiLayoutLeft2Line`）

### 动画效果

**展开 → 折叠**：
```
宽度：236px → 0px
内边距：4px → 0px
时长：200ms
```

**折叠 → 展开**：
```
宽度：0px → 236px
内边距：0px → 4px
时长：200ms
```

## 🖱️ 桌面端 - Hover 弹出面板

### 代码位置

**文件**：`web/app/components/base/chat/chat-with-history/index.tsx`
**行数**：第 70-80 行

### 完整代码

```tsx
{isSidebarCollapsed && (
  <div
    className={cn(
      'absolute top-0 z-20 flex h-full w-[256px] flex-col p-2 transition-all duration-500 ease-in-out',
      showSidePanel ? 'left-0' : 'left-[-248px]',
    )}
    onMouseEnter={() => setShowSidePanel(true)}
    onMouseLeave={() => setShowSidePanel(false)}
  >
    <Sidebar isPanel />
  </div>
)}
```

### 代码解析

**条件渲染**：
```tsx
{isSidebarCollapsed && ...}
```
- 只在侧边栏折叠后显示
- 当 `isSidebarCollapsed === true` 时启用

**容器样式**：
```tsx
className={cn(
  'absolute top-0 z-20 flex h-full w-[256px] flex-col p-2 transition-all duration-500 ease-in-out',
  showSidePanel ? 'left-0' : 'left-[-248px]',
)}
```
- `absolute` - 绝对定位（脱离文档流）
- `top-0` - 距离顶部 0
- `z-20` - 层级 20（高于主内容区）
- `h-full` - 高度 100%
- `w-[256px]` - 宽度 256px（比正常侧边栏宽 20px）
- `flex-col` - 垂直方向排列
- `p-2` - 内边距 8px
- `transition-all duration-500` - 平滑过渡（500ms，比正常慢）
- `ease-in-out` - 缓动函数

**滑动效果**：
```tsx
showSidePanel ? 'left-0' : 'left-[-248px]'
```
- 显示时：`left: 0` - 完全显示
- 隐藏时：`left: -248px` - 大部分隐藏，只留 8px 触发区域

**鼠标事件**：
```tsx
onMouseEnter={() => setShowSidePanel(true)}
onMouseLeave={() => setShowSidePanel(false)}
```
- 鼠标进入 → 显示面板
- 鼠标离开 → 隐藏面板

**Sidebar 组件**：
```tsx
<Sidebar isPanel />
```
- **关键**：传入 `isPanel={true}`
- Sidebar 内部会添加面板样式（圆角、边框、阴影）

### 状态控制

**状态变量**：
```tsx
const [showSidePanel, setShowSidePanel] = useState(false)
```
- 局部状态（useState）
- 默认值：`false`（隐藏）

**触发条件**：
1. 侧边栏已折叠（`isSidebarCollapsed === true`）
2. 鼠标移入触发区域

### 动画效果

**隐藏 → 显示**：
```
left: -248px → 0px
时长：500ms
触发：鼠标进入
```

**显示 → 隐藏**：
```
left: 0px → -248px
时长：500ms
触发：鼠标离开
```

### 尺寸计算

**为什么宽度是 256px？**
- 正常侧边栏：236px（内容宽度）
- Hover 面板：256px（内容 + 额外 padding）
- 额外的 20px 用于：
  - 面板内边距增加（`p-1` → `p-2`，即 4px → 8px）
  - 视觉上稍宽，区分面板和正常侧边栏

**为什么 left 是 -248px？**
- 面板宽度：256px
- 保留触发区域：8px
- 隐藏宽度：256px - 8px = 248px
- 所以 `left: -248px` 可以保留 8px 在左边缘作为触发区域

## 📱 移动端 - 点击弹出侧边栏

### 代码位置

**文件**：`web/app/components/base/chat/chat-with-history/header-in-mobile.tsx`
**行数**：第 106-114 行

### 完整代码

```tsx
{showSidebar && (
  <div className='fixed inset-0 z-50 flex bg-background-overlay p-1'
    onClick={() => setShowSidebar(false)}
  >
    <div className='flex h-full w-[calc(100vw_-_40px)] rounded-xl shadow-lg backdrop-blur-sm'
         style={{ backgroundColor: '#615e5f' }}
         onClick={e => e.stopPropagation()}>
      <Sidebar />
    </div>
  </div>
)}
```

### 代码解析

**条件渲染**：
```tsx
{showSidebar && ...}
```
- 当 `showSidebar === true` 时显示
- 由点击菜单按钮触发

**遮罩层**：
```tsx
<div className='fixed inset-0 z-50 flex bg-background-overlay p-1'
  onClick={() => setShowSidebar(false)}
>
```
- `fixed` - 固定定位（相对于视口）
- `inset-0` - 上下左右都为 0（全屏覆盖）
- `z-50` - 层级 50（高于所有内容）
- `flex` - Flexbox 布局
- `bg-background-overlay` - 半透明黑色遮罩
- `p-1` - 内边距 4px
- `onClick={() => setShowSidebar(false)}` - 点击遮罩关闭

**侧边栏容器**：
```tsx
<div className='flex h-full w-[calc(100vw_-_40px)] rounded-xl shadow-lg backdrop-blur-sm'
     style={{ backgroundColor: '#615e5f' }}
     onClick={e => e.stopPropagation()}>
```
- `flex` - Flexbox 布局
- `h-full` - 高度 100%
- `w-[calc(100vw_-_40px)]` - 宽度 = 视口宽度 - 40px
  - 左右各留 20px 空白（因为遮罩 `p-1` = 4px + 侧边栏外边距）
- `rounded-xl` - 大圆角
- `shadow-lg` - 大阴影
- `backdrop-blur-sm` - 背景模糊（毛玻璃效果）
- `backgroundColor: '#615e5f'` - 品牌深灰色
- `onClick={e => e.stopPropagation()}` - 阻止事件冒泡（避免点击侧边栏时关闭）

**Sidebar 组件**：
```tsx
<Sidebar />
```
- 无 `isPanel` prop，使用正常模式
- 但容器自带圆角和阴影

### 触发按钮

**位置**：`header-in-mobile.tsx:69-71`

```tsx
<ActionButton size='l' className='shrink-0' onClick={() => setShowSidebar(true)}>
  <RiMenuLine className='h-[18px] w-[18px]' />
</ActionButton>
```
- 菜单图标按钮（三条横线）
- 点击后 `setShowSidebar(true)`

### 状态控制

**状态变量**：
```tsx
const [showSidebar, setShowSidebar] = useState(false)
```
- 局部状态（useState）
- 默认值：`false`（隐藏）

**开启方式**：
1. 点击菜单按钮（`RiMenuLine`）
2. `setShowSidebar(true)`

**关闭方式**：
1. 点击遮罩层（黑色半透明区域）
2. 完成操作后（如选择对话）- 需要手动触发

### 关闭逻辑

**点击遮罩关闭**：
```tsx
onClick={() => setShowSidebar(false)}
```

**点击侧边栏内部不关闭**：
```tsx
onClick={e => e.stopPropagation()}
```
- 阻止事件冒泡到遮罩层
- 确保点击侧边栏内容时不会关闭

### 尺寸计算

**为什么宽度是 `calc(100vw - 40px)`？**
- 视口宽度：`100vw`
- 遮罩内边距：`p-1` = 4px × 2 = 8px（左右）
- 侧边栏外边距：约 16px × 2 = 32px
- 总计留白：8px + 32px = 40px
- 侧边栏宽度：`100vw - 40px`

**视觉效果**：
```
┌────────────────────────────┐ ← 视口边界
│ [遮罩 4px]                 │
│ ┌────────────────────────┐ │
│ │ [侧边栏内容]           │ │ ← 侧边栏
│ │                        │ │
│ │                        │ │
│ └────────────────────────┘ │
│ [右侧留白 ~20px]           │
└────────────────────────────┘
```

## 🐛 常见问题

### Q1: 为什么修改了代码，Hover 面板没有变化？

**原因**：可能只修改了容器，没有修改 Sidebar 组件本身。

**解决**：
- 如果是背景色、内容等，修改 `sidebar/index.tsx`
- 如果是宽度、动画，修改 `index.tsx`

### Q2: 移动端侧边栏样式和桌面端不一致？

**原因**：移动端的圆角、阴影由容器提供，不是 Sidebar 组件本身。

**解决**：
- 检查 `header-in-mobile.tsx:110` 的容器样式
- 确保容器和 Sidebar 都应用了品牌色

### Q3: Hover 面板显示不出来？

**检查清单**：
1. 侧边栏是否已折叠（`isSidebarCollapsed === true`）
2. 鼠标是否移入了触发区域（左侧 8px）
3. `showSidePanel` 状态是否正确切换
4. `left-[-248px]` 是否正确（与宽度匹配）

### Q4: 如何在侧边栏添加新内容？

**步骤**：
1. 打开 `sidebar/index.tsx`
2. 在适当位置添加新的 JSX
3. 保存后自动生效（所有 3 种侧边栏）

**建议位置**：
- 顶部区域：第 88-111 行之间
- 按钮下方：第 117 行之后
- 列表区域：第 124-140 行之间
- 底部区域：第 142 行之后
